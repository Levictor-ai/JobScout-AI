# JobScout AI UI Specification

## Design Direction

Modern AI SaaS.

Visual characteristics:

* Minimal
* Clean
* High information density
* Strong typography
* Excellent spacing
* Responsive
* Desktop first
* Mobile compatible

---

## Navigation

Sidebar:

* Dashboard
* Discover
* Saved
* Applications
* Companies
* Profile
* Settings

---

## Dashboard

Display:

### Header

"Good morning"

Subheading:

"Here are the latest opportunities matching your profile."

---

### Stats

* New jobs
* High matches
* Saved
* Applications
* Interviews

---

### High Match Jobs

Each card should show:

* Company
* Job title
* Location
* Remote status
* Match
* Posted date
* Short AI summary
* Apply button
* Save button

---

## Discover Page

Filters:

* Role
* Location
* Remote
* Seniority
* Match
* Company
* Source
* Date posted

---

## Job Detail

Sections:

1. Job overview
2. AI summary
3. Why it matches
4. Potential gaps
5. Requirements
6. Responsibilities
7. Company
8. Application

User can configure:

* Target roles
* Skills
* Experience
* Location
* Preferred locations
* Remote preference
* Employment type
* Portfolio
* Resume

## Companies
