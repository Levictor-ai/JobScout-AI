# JobScout AI

## Project Context

### Project Identity

Name: JobScout AI

Type: AI powered job discovery and matching platform

Primary purpose:

Automatically discover relevant job opportunities from company career systems and public job sources, then use AI to filter and explain which opportunities are relevant to the user.

---

## Employment Preferences

Prioritize:

* Remote
* Full time
* Contract
* Freelance

The system should not exclude opportunities solely because salary information is unavailable.

---

## Product Philosophy

The product should reduce noise rather than create more noise.

Do not show hundreds of irrelevant jobs simply because they match a keyword.

Every recommendation should have an explainable reason.

---

## AI Philosophy

AI should assist the user rather than make irreversible decisions.

AI may:

* Analyze
* Classify
* Summarize
* Compare
* Explain
* Prioritize

AI should not:

* Apply automatically
* Invent information
* Misrepresent qualifications
* Make decisions on behalf of the user without transparency

---

## Design Direction

The interface should feel:

* Modern
* Minimal
* Professional
* Fast
* Information dense without feeling cluttered
* AI native
* SaaS quality

Use a clean visual hierarchy.

Avoid unnecessary gradients, excessive animations, and decorative UI that does not improve usability.

## Development Principle

Build incrementally.

Do not build every feature at once.

Start with:

Database → source integration → ingestion → classification → matching → dashboard → tracking.

Every stage should produce a working feature before moving to the next stage.
